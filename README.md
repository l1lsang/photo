# 📸 네컷 스튜디오

컴퓨터 카메라로 사진 10장을 찍고, 마음에 드는 4장을 골라 프레임으로 꾸민 뒤 저장·인쇄하는 네컷 사진 프로그램입니다.

## 실행

```bash
npm install     # 처음 한 번
npm run dev     # http://localhost:5173 을 Chrome 또는 Edge 로 열기
```

처음 열면 브라우저가 카메라 권한을 묻습니다. **허용**을 눌러 주세요.
(카메라는 `localhost` 또는 `https` 주소에서만 동작합니다. `dist/index.html` 파일을 직접 더블클릭하면 열리지 않으니 `npm run dev` 또는 `npm run build && npm run preview` 로 실행하세요.)

## 기능

| 단계 | 내용 |
| --- | --- |
| 1. 촬영 | 10장 자동 연속 / 한 장씩 촬영, 타이머 3·5·10초, 거울 모드, 실시간 필터, 효과음, 카메라 선택, `Space` 키 촬영 |
| 2. 고르기 | 10장 중 4장 선택 (고른 순서대로 칸에 배치), 오른쪽에서 결과 미리보기 |
| 3. 꾸미기 · 구조 | 12종: 클래식 세로 · 슬림 세로 · 로고 위 세로 · 2×2 그리드 · 2×2 슬림 · 2×2 굵은 틀 · 로고 위 2×2 · 가로 스트립 · 빅 원+3 · 시네마 · 폴라로이드 · 지그재그 |
| 3. 꾸미기 · 프레임 | 12종: 화이트 · 블랙 · 라인 · 러블리 핑크 · 구름 하늘 · 필름 · 레트로 체크 · 민트 도트 · 선셋 · 할로윈 · 크리스마스 · 직접 고르기, 사진 모서리 둥글게 |
| 3. 꾸미기 · 보정 | 필터 9종, 밝기 · 대비 · 채도 · 색온도 · 뽀샤시 피부 · 비네팅, 거울 모드 |
| 3. 꾸미기 · 문구 | 원하는 문구, 촬영 날짜, 글꼴 7종, 글자색 |
| 4. 저장·인쇄 | 300dpi PNG 저장 (`Ctrl+S`), 인쇄 (`Ctrl+P`) — 4×6 인화지 또는 A4 실제 크기, 스트립은 2장을 이어 붙여 한 장에 인쇄 |

설정(구조·프레임·문구 등)은 브라우저에 저장되어 다음에 열 때도 유지됩니다.

## 내 프레임 추가하기

꾸미기 → **프레임** 탭 → **＋ 프레임 이미지 추가** (클릭하거나 이미지를 끌어다 놓기)

| 올린 이미지 | 동작 |
| --- | --- |
| 사진 자리 **4곳을 투명하게 비운 PNG** | 투명한 칸을 자동으로 찾아 그 아래에 사진 4장을 넣고, 프레임 이미지를 위에 덮습니다. 칸 모양(네모·동그라미 등)과 배치는 자유이고, 문구·날짜는 이미지에 그린 그대로 나옵니다. |
| 투명한 곳이 **없는** 이미지 (JPG 등) | 지금 고른 구조의 **배경**으로 깔립니다. 문구·날짜도 그대로 쓸 수 있어요. |

- 크기를 맞추기 쉽게 **템플릿 받기**를 누르면 지금 구조의 사진 칸이 투명하게 뚫린 PNG(300dpi)를 받을 수 있어요. 그 위에 꾸민 뒤 **투명 배경 PNG**로 저장해 올리세요. (포토샵, [포토피아](https://www.photopea.com) 등)
- 이미지 비율은 자유이고, 긴 변을 1800px(6인치)에 맞춰 저장합니다. 세로로 긴 스트립(1:3 정도)은 인쇄할 때 2장을 이어 붙입니다.
- 투명한 칸이 4개가 아니면 추가되지 않아요. 아주 작은 투명 조각(전체의 1% 미만)은 칸으로 세지 않습니다.
- 추가한 프레임은 브라우저(IndexedDB)에 저장되어 다음에 열 때도 남아 있고, 카드의 ✕ 로 삭제할 수 있어요.

### 인쇄 팁

- 포토 프린터라면 인쇄 창에서 용지를 **4×6 (10×15cm)** 으로, 여백을 **없음**으로 고르세요.
- 일반 프린터는 꾸미기 화면에서 용지를 **A4 실제 크기**로 바꾸면 실제 사진 크기로 가운데에 인쇄됩니다.

## 폴더 구조

```text
src/
  App.tsx                 단계(시작 → 촬영 → 고르기 → 꾸미기) 전환과 전체 상태
  components/
    HomeScreen.tsx        시작 화면
    ShootScreen.tsx       카메라 · 카운트다운 · 연속 촬영
    SelectScreen.tsx      4장 고르기
    EditScreen.tsx        구조 · 프레임 · 보정 · 문구 · 저장/인쇄
    PreviewCanvas.tsx     결과 미리보기 캔버스
  hooks/useCamera.ts      카메라 스트림 열기/닫기, 오류 안내
  lib/
    layouts.ts            구조(칸 배치) 정의 — 300dpi 픽셀 좌표
    themes.ts             프레임 디자인 · 글꼴
    filters.ts            필터 · 보정값
    render.ts             프레임 합성 (배경 · 장식 · 사진 보정 · 문구)
    customFrames.ts       내 프레임: 투명 칸 찾기 · 템플릿 만들기
    frameStore.ts         내 프레임 보관 (IndexedDB)
    output.ts             PNG 저장 · 인쇄
```

새 구조는 `lib/layouts.ts` 의 `LAYOUTS` 에, 새 프레임은 `lib/themes.ts` 의 `THEMES` 에 항목을 추가하면 화면에 바로 나타납니다.
